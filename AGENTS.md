# Entrega del programa

Cuando se cambie código de MercadohouseSync, ejecutar las pruebas y generar `MHSync.exe` con `MercadohouseSync.spec`. Dejarlo listo para abrir y dar al usuario su ruta exacta. La versión va en `version.py` y dentro del menú, no en el nombre del archivo. El punto de entrada es `menu.py`; `utils.py` y los módulos `sync_*.py` no se abren directamente para probar el programa completo.

No publicar una versión en GitHub ni reemplazar el ejecutable estable sin que el usuario lo pida.
